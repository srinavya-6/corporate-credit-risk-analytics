# Corporate Credit Risk Analytics Dashboard

This project is an interactive Streamlit application designed for financial data analysis, corporate leverage evaluation, credit ratio calculation, and Altman Z-Score default risk forecasting.

## How to Run Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   streamlit run app.py
   ```

3. Open your browser at `http://localhost:8501`.
